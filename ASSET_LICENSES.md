# Asset Licenses

This file tracks the license of every external (non-code) asset used in the
project — models, textures, audio, fonts, etc. — per Master Blueprint
Section 30-31. It must be updated **before** any external asset is merged
into `main`.

## Phase 1 status

No external assets are used in Phase 1. All 3D content (ground, sky dome,
placeholder object) is generated procedurally from Three.js primitives and
inline shaders — no `.glb`, texture, or audio files are included.
